# Design and look

Code: `index.html` (markup), `css/style.css`, `js/library.js` (GAMES / STORED lists).

- Games come only from the R2 bucket (GAMES list). There is no load-from-device UI. Playing a
  cloud game caches it in this browser's STORED list (IndexedDB `rom-library`) so later launches are instant.
  A game that is in STORED has its Play button hidden in GAMES. Remove in STORED asks for confirmation. For a DS game it
  also deletes that game's saves on this device (both cores' local files and this device's cloud slot, see
  docs/save-sync.md); if the cloud delete fails, nothing is removed.
- To add a game, Kenny uploads the ROM to the `pokemon-roms` bucket in the Cloudflare dashboard. It shows
  up after a page reload with no code change. Known DS codes in `NDS_GAMES` (IPK HeartGold, IPG
  SoulSilver, ADA Diamond, APA Pearl, CPU Platinum) get a proper title and color tag; anything else shows
  its file name. `functions/api/roms.js` reads that code from R2 with a 4-byte ranged read (offset 0x0C),
  so titles show before download. It hides the `saves/` prefix.
- Game rows show only the color tag, the title and the buttons. No file name or size subtitle.

Gen 2 (Gold/Silver/Crystal) Game Boy Color look. No instructional copy on the page, keep labels terse.
- Logo reads KENNY'S / POKéMON / PLAYER; the tab title is "Kenny's Pokémon Player".
- Fonts: Press Start 2P (UI) and VT323 (secondary text), from Google Fonts.
- White double-bordered "text boxes" (`.box`), section tabs (GAMES / STORED), ▶ cursor on
  button hover/focus.
- Background: pixel-art SVG `scene.svg` (`#scene`, 256x144 logical px, `preserveAspectRatio="xMidYMax slice"`)
  generated by `tools/scene.py`; a one-line script in `index.html` fetches it and inlines it at the top of
  `<body>` so the CSS variables apply. Its fills are CSS variables. `html[data-time]` switches the
  MORN (4-10) / DAY (10-18) / NITE (18-4) palettes, and a Gen 2 style clock shows the period.
- Original art only. Don't draw actual Pokémon or copy official logos or artwork.
  One exception, Kenny's call (2026-10-24): the in-game guide panel shows the real HGSS Pokémon
  sprites and item icons, hot-linked from PokeAPI's sprite repo on GitHub. Never commit them.
- To change the scene: edit `tools/scene.py` and run `python3 tools/scene.py` from the repo root; it
  rewrites `scene.svg`. Don't read or edit `scene.svg` by hand (one 29 KB line).
